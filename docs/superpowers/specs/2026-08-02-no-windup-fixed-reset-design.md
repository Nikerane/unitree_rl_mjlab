## Goal

Test whether one-shot Cartesian guideline progress produces a straight hammer strike without confounding the experiment with an artificial upward wind-up or randomized initial pose.

## Decisions

1. The active `SingleStrikeReference` is one segment from the realized reset hammer-head position to a follow-through target directly below the frozen nail top.
2. No target generated by the reference may rise above the reset hammer-head position.
3. C0 and C-Gate use the same fixed nominal reset in both training and play/evaluation. PPO seeds remain independent; only physical reset perturbation is removed.
4. The existing six ordered gates remain on the reset-head-to-nail segment. With the fixed aligned reset this is the intended near-vertical strike line.
5. C0 and C-Gate remain identical except for `r_gate`; fixed impedance, action scale, manufacturer limits, and `imp_max_p=0.0` remain unchanged.
6. The historical `r_imit` implementation stays disabled in this experiment. Its active reference reader follows the new one-segment geometry, but no imitation payout is introduced.
7. Dated result documents and result-asset probes retain their historical wording and provenance. Current production code, active scripts, living documentation, and tests must not describe or require an upward wind-up.

## Reference Geometry

At reset, freeze hammer-head position `p0` and nail-top position `pn`. Define the follow-through target

```text
pt_xy = pn_xy
pt_z = min(pn_z - overshoot, p0_z)
u  = (pt - p0) / ||pt - p0||
p(phi) = p0 + phi * (pt - p0),  phi in [0, 1]
```

The target-height clamp is intentional: if a realized reset puts the hammer head below the nominal nail-derived follow-through height, only `pt_z` is clamped to `p0_z`; the nail-derived x/y target is preserved. This prevents a low reset from turning the direct strike into an upward command.

Spatial phase is the clamped projection of the current head onto this segment, gated by the existing lateral-axis tolerance and monotonically latched. It is not clock-indexed. Scripted playback advances along the same segment by at most `descent_speed` metres per control step.

## Fixed Reset Scope

Only the new Cartesian guideline arms force `reset_robot_joints.position_range=(0.0, 0.0)` during training. Legacy arms keep their existing training randomization. This preserves historical contracts while making the causal C0/C-Gate comparison apples-to-apples.

## Qualification

Before GPU training, the fixed-reset scripted playback must:

- never increase commanded head height above the reset height;
- cross all six ordered gates;
- remain within the 5 mm corridor from gate 1 through accepted first contact;
- drive the nail;
- keep every arm joint at or below 3.1415 rad/s;
- produce only finite actions and traces.

The qualification uses multiple execution seeds to detect nondeterministic plumbing, but they must realize one identical physical reset state.

## Non-Goals

- no variable impedance or `set_gains`;
- no hard tube termination;
- no reset curriculum yet;
- no changes to manufacturer impulse caps;
- no enabling of impulse enforcement;
- no broad rewrite of archived result evidence.
