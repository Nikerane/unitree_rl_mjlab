# Resolution for Freeze the controlled-drop reference setup

## Answer

The primary calibration is simulation-only: a centered constrained 0.200 kg
flat cylindrical dropper released from rest at the hammer-head start height
`h0`, using the production nail/contact measurement path. Other heights and the
0.245 kg hammer-plus-fixture sensitivity condition are optional follow-ups and
must remain separate.

## Evidence

The setup and mass distinction are frozen in the
[post-meeting handoff](../../../../results/2026-08-06_PRESENTATION_HANDOFF.md).

## Consequences

The drop supplies an independent delivered nail-impulse reference scale; it does
not reproduce the arm's controller- and configuration-dependent effective mass.
