# Resolution for Freeze the high-level VIC architecture

## Answer

Branch VIC from the verified direct-joint baseline. Keep the same desired
joint-position action and add bounded per-joint proportional stiffness that can
move below or above nominal; couple damping to stiffness. Retain the same P
task-space guidance and frozen `r_tt`, introduce changes incrementally, and put
VIC after fixed-gain, drop, active-CaT, and robustness stages.

## Evidence

This is the owner-approved paper-aligned architecture recorded in the
[post-meeting handoff](../../../../results/2026-08-06_PRESENTATION_HANDOFF.md).

## Consequences

Nominal constant gains must reproduce the fixed controller before any learned
VIC campaign. Exact gain ranges, mapping, reset, observations, and telemetry
remain open decisions.
