# Resolution for Map paper VIC semantics onto a safe Z1 gain contract

## Answer

Use the paper's centered per-joint logarithmic mapping `m=C**p`,
`Kp=m*Kp0`, `Kd=sqrt(m)*Kd0`, so `p=0` exactly reproduces FIC. Retain the
native `BuiltinPositionActuator`; its matched variable-gain path updates per-world
MuJoCo `gainprm` and `biasprm`, because that actuator has no literal `set_gains()`
method. Switching only VIC to explicit Python PD would invalidate matching.

The paper does not supply a transferable Z1 bound. Prototype common
`C={1.25,1.5,2.0}` in ascending order, with nominal-reproduction, per-environment
isolation, saturation, telemetry, reset, and CPU/CUDA stability gates before
freezing a value.
