# Resolution for Define the causal command-trackability term

## Answer

Use the nonnegative cost
`k_tt * ||q_des(t) - q(t+1)||^2` with reward weight `-1.0`. Calibrate `k_tt`
once from the qualified scripted fixed-gain replay, retain the same frozen value
for FIC and VIC, and classify `r_tt` as an unscaled negative CaT term.

## Evidence

The causal indexing follows Bogdanovic, Khadiv, and Righetti; the paper and FIC
scope are summarized in the [`r_tt` audit](../../../../research/khadiv_fic_rtt_audit.md).
The implementation and calibration details live in the
[Stage-1 implementation plan](../../../../superpowers/plans/2026-08-06-z1-joint-position-fixed-stage1.md).

## Consequences

Velocity violations cannot discount the tracking penalty. FIC and VIC differ in
gain authority, not in tracking-term definition or coefficient.
