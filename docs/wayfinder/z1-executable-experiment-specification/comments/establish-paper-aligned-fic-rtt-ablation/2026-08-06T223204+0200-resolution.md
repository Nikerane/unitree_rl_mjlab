# Resolution for Establish the paper-aligned FIC RTT ablation

## Answer

Train matched fixed-gain direct-joint policies both without and with `r_tt` so
its effect can be measured before VIC. The no-`r_tt` task is no longer merely an
engineering configuration check. Campaign depth, promotion, and estimands remain
separate open decisions.

## Evidence

The paper explicitly evaluates fixed-gain PD without and with `r_tt`; see the
[primary-source audit](../../../../research/khadiv_fic_rtt_audit.md). The owner
then requested the same comparison for Z1.

## Consequences

FIC-no-TT versus FIC-TT isolates the tracking term. The later impedance-isolation
comparison should use FIC-TT versus VIC-TT with the same frozen `r_tt`.
