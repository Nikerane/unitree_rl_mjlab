# Fixed500Hz PD, independent physics timestep — 2026-09-23

## Conclusion

The finer native-PD tests did **not** establish behavior at500Hz PD updates.
This corrected diagnostic updates PD only every2ms and holds clipped torque
between ticks. With this controller, J6 oscillation and speed violations return
under both tested gain vectors. Smaller physics steps alone are not a remedy.
No production controller changes or new training were made.

This is a sampled-PD simulation under the user's500Hz assumption, not a
validated replica of Z1 firmware/current-loop bandwidth, latency or filtering.
Ideal body gravity compensation and physical passive damping remain unchanged.

change; even2ms physics is not expected to reproduce the earlier native model.
